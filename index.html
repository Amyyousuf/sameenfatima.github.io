Algorithm Design
NED Route Optimizer

A Streamlit web app that finds the best route to NED University from anywhere in Karachi — pick a starting point (Millennium Mall, Korangi, Malir Halt, and more) and it computes the shortest path using either Dijkstra's algorithm or A* search over a real map graph, with live locations pulled from OpenRouteService. Both algorithms always return the same optimal route, but A* gets there faster by making smart guesses about direction instead of exhaustively checking every path — the app surfaces total distance in km alongside the interactive map so the tradeoff is visible, not just theoretical.
